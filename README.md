
# Bento Grid - Bootstrap 5 Project

## Project Overview

This project is part of my Design and Development SBA 3. I chose the Bento Grid challenge from Frontend Mentor to practice building a responsive webpage using HTML, CSS, and Bootstrap 5.

The goal was to recreate the provided Figma design as closely as possible for desktop, tablet, and mobile screens.

## Frontend Mentor Challenge

[Bento Grid Challenge](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj)

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.9
- Google Fonts (DM Sans)
- Git and GitHub
- Visual Studio Code

## My Approach

I started by looking at the Figma design and understanding how the eight cards were arranged.

I used Bootstrap's grid system with rows and columns to create the layout. I also used Bootstrap utility classes for spacing, padding, alignment, and responsiveness.

I added custom CSS to match the colors, font sizes, card heights, and image positions from the Figma design.

I used media queries for desktop, tablet, and mobile layouts and tested the webpage using Chrome Developer Tools.

## Challenges I Faced

One of the biggest challenges was aligning the left and right sections on desktop. I had to adjust the card heights and spacing several times to make the bottom sections line up.

Another challenge was getting the images and headings to fit inside the cards. Some headings were getting cut off, and some images were too large.

I worked on these issues by adjusting the CSS properties, Bootstrap classes, and media queries.

## What I Learned

- How to use Bootstrap's 12-column grid system.
- How to work with nested Bootstrap rows and columns.
- How to use Flexbox for alignment.
- How to use Bootstrap utility classes.
- How to create responsive layouts with media queries.
- How to use browser Developer Tools to check and fix layout issues.

## Future Improvements

If I had more time, I would improve the spacing, typography, and card positioning to make the webpage even closer to the Figma design.

I would also test the website on more devices to make sure it looks good on different screen sizes.

## Reflection

Working on this Bento Grid project helped me understand Bootstrap and responsive web design better. At first, I thought arranging the cards would be simple, but I realized that matching a Figma design requires careful attention to spacing, alignment, and image sizes.

One of my main challenges was getting the left and right sections to align properly on desktop. I also had issues with headings getting cut off and images not fitting correctly inside the cards. I tried different Bootstrap utility classes and adjusted my CSS to fix these problems.

Testing the webpage using Chrome Developer Tools helped me understand how the layout changes between desktop, tablet, and mobile screens. I also learned that changing one CSS property can sometimes affect other parts of the page.

If I had more time, I would improve the design accuracy and test it on more devices. Overall, this project gave me more confidence in using Bootstrap and CSS to build responsive webpages.
