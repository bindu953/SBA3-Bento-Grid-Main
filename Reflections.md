
## 5. Reflection

### 1. What challenges did you encounter during the project?

One of the main challenges I faced was understanding the Bootstrap grid and utility classes and getting the cards to align properly, especially the left and right sections in the desktop layout. Some headings were getting cut off because of the card heights, and a few images were not positioned correctly. I also had difficulty matching the spacing and layout with the original Figma design.

### 2. How did you approach solving these challenges?

I started by reviewing my HTML structure and Bootstrap grid classes to understand what was causing the issues. I made changes to the card heights, padding, gaps, and image sizes using custom CSS. I also used media queries to adjust the layout for desktop, tablet, and mobile screens. I tested my changes using Chrome Developer Tools and compared the results with the Figma design. This helped me identify mistakes and improve the layout step by step.

### 3. What improvements would you make if you had more time?

If I had more time, I would focus on making the webpage even closer to the Figma design, especially the font sizes, image cropping, and spacing between cards. I would also test the website on more devices and improve the code by removing unnecessary CSS rules to make it cleaner and easier to maintain. I would also have explored tailwind classes to implement using tailwind and style the page more as and when  needed .
